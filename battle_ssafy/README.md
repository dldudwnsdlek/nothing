# 배틀싸피 팀 대항전 봇 (Python)

`main.py` 하나를 팀원 3명이 그대로 사용하고, `NICKNAME`만 각자 `지역반_이름`으로 바꾸면 됩니다.
3대가 같은 코드를 쓰지만 맵을 보고 **누가 어느 사격 레인을 맡을지 스스로 나눕니다.**

## 1. 자료 분석: 승패를 가르는 규칙

| 규칙 | 전략에 주는 의미 |
|---|---|
| 승리 우선순위: ① 상대 시간초과/런타임 에러 → ② **포탑 파괴** → ③ 적 탱크 2대 파괴 → ④ 100턴 후 피해량/거리/후공 | 에러 없이 끝까지 돌기만 해도 최소 무승부 수준. 실제 승부는 **포탑 레이스** |
| 포탑 체력 100, 일반탄 30, 메가탄 70, 사거리 3(직선) | 일반탄만 쓰면 4발, **메가 1 + 일반 1이면 2발** |
| 내 탱크는 **내 포탑 주변 3×3**에 들어갈 수 없음 | 상대도 자기 포탑 앞을 몸으로 막을 수 없음 → 돌격이 유리 |
| 모서리 포탑은 사격 가능한 직선(레인)이 2개뿐이고, 같은 레인 뒤쪽 탱크는 앞 탱크에 가려짐 | **포탑을 동시에 쏠 수 있는 탱크는 레인당 1대, 최대 2대.** 3대가 몰려가면 1대는 놀게 됨 |
| 옐로카드 3장 = 탱크 아웃 (아웃 2대 = 패배) | S·회전만 하기, 막힌 칸 이동, 허공/바위/보급시설 사격, 메가 없이 FM, 메가 10개에서 G → **전부 사전에 차단** |
| 보급시설 인접 시 암호문 → `G 해독문` 성공 시 메가 +1 | 레인이 2개뿐이라 메가가 있으면 포탑 처치가 1라운드 빨라짐 |
| 모래 통과 시 체력 -10 | 시간이 1턴 이상 줄어들 때만 모래를 밟고, 체력 10 이하이면 절대 밟지 않음 |

연습 맵(OT 화면 복원)은 점대칭이고, **보급시설이 적 포탑 바로 앞에 있습니다.** 적 포탑으로 가는 길에 메가탄을 줍도록 설계된 맵입니다.

## 2. 전략 (매 턴 우선순위)

1. **포탑을 쏠 수 있으면 쏜다.** 이번 한 발로 부술 수 있으면 즉시 쏩니다. 메가가 있으면 메가를 씁니다.
   (이미 적 1대를 잡았고 이번 사격으로 2번째를 잡을 수 있으면 그것도 즉시 승리이므로 우선합니다.)
2. **한 방에 죽는 적 탱크는 바로 처치**합니다 (체력 30 이하는 일반탄, 70 이하는 메가). 2대를 잡으면 승리합니다.
3. **레이스 판단:** 우리 팀과 적 팀이 각자 상대 포탑을 부수는 데 걸리는 라운드를 매 턴 추정합니다.
   우리가 지고 있으면 우리 포탑을 쏠 수 있는 적 탱크부터 집중 사격합니다.
4. **선제 교전:** 사선이 겹친 적 탱크(서로 쏠 수 있는 위치)는 먼저 쏘는 쪽이 이기므로 체력이 낮은 적부터 먼저 쏩니다.
5. **이동(레인 배정):** 아군 3대 각각이 Dijkstra로 거리를 구합니다. 비용은 풀 1, 모래 1.4, 나무 2(사격 1 + 이동 1)입니다.
   여기서 "레인당 1대" 배정을 전수 탐색해 **포탑이 가장 빨리 부서지는 배정**을 고르고, 내 역할을 정합니다.
   - 레인 담당: 보급시설을 경유하는 편이 처치 라운드가 같거나 빠르면 메가 1발을 확보한 뒤 레인으로 갑니다.
   - 남는 탱크(지원): 메가 2발을 확보한 뒤 우리 포탑에 가까운 적 탱크를 사냥합니다.
   - 경로 위 나무는 쏴서 뚫고, 레인에 도착했는데 나무/적이 가리면 그것부터 쏩니다.
6. **안전장치**
   - 예외가 나도 `fallback()`이 이동이나 유효한 사격을 반환하므로 프로그램이 죽지 않습니다.
   - 이동이 거부된 칸(규칙 해석이 달랐던 경우)은 기억해 두고 다시 가지 않습니다. 같은 옐로카드를 반복하지 않습니다.
   - 아군과 우리 포탑 방향으로는 절대 쏘지 않습니다.
   - 수신 데이터가 잘려 들어와도 헤더의 행 수만큼 다 받을 때까지 이어서 수신합니다.

### 카이사르 암호
- 매뉴얼 예시(`SRKKCVJJRWP → BATTLESSAFY`)의 간격(복호 +9)을 1순위로 시도합니다.
- 그 외 간격은 영어 빈도와 단어 사전 점수로 순위를 매깁니다.
- `G` 직후 메가 수가 늘었는지 보고 성공한 간격은 고정하고, 실패한 간격은 제외합니다. 4번 연속 실패하면 메가를 포기하고 레이스에 집중합니다.

## 3. 로컬 시뮬레이터 검증 (`sim/`)

`python3 sim/sim.py 10`을 실행하면 연습 맵과 랜덤 대칭 맵 10개에서 양쪽 진영(A/B)으로 다음 상대들과 대전합니다.

| 상대 봇 | 설명 |
|---|---|
| rusher | 가장 가까운 사거리 3 위치로 돌격해 포탑 사격 |
| adjrusher | 기본 코드 스타일(포탑 바로 옆까지 BFS) |
| megarusher | 메가 2발 확보 후 돌격 |
| hunter | 사선의 적 탱크를 무조건 사격 |
| mirror | 같은 코드에서 교전 로직만 끈 버전 |

최종 버전 결과 (연습 맵 + 랜덤 맵 10개, A/B 양 진영 = 상대별 22판):

| 상대 | 승/패 | 비고 |
|---|---|---|
| rusher | 21 / 1 | |
| adjrusher (기본 코드형) | 22 / 0 | |
| megarusher | 22 / 0 | |
| hunter | 18 / 4 | 교전 로직 추가 전에는 12 / 10 |
| mirror (완전히 같은 코드) | 11 / 11 | 대칭 맵에서는 선공이 유리해 반반이 정상 |

- 우리 팀 옐로카드 0회, 아군 오인 사격 0회, 런타임 에러 0회입니다. 턴 순서를 A1 A2 A3 B1 B2 B3로 바꾸고 죽은 탱크를 목록에 남기는 변형 규칙 72판에서도 같았습니다.
- 한 턴 계산 시간은 평균 10ms, 최대 30ms입니다 (제한 60초).
- 소켓 모의 서버로 데이터를 일부러 두 조각으로 나눠 보내는 상황도 검증했습니다.

튜닝 실험 요약 (상대 5종 × 22판 = 110판 기준 총 승수):

| 교전 방식 | 총 승수 |
|---|---|
| 교전 안 함 (레이스만) | 88 |
| 사선의 적은 항상 선제 사격 | 92 |
| 맞은 적 있을 때 / 적 체력 60 이하 / 적이 우리 포탑을 노릴 때만 | 95 |
| 위 조건 + 적 체력이 내 체력보다 낮을 때 **(채택)** | **96** |
| 채택안에서 메가 우회 확보만 끔 | 90 |

시뮬레이터는 매뉴얼/OT 규칙을 추정해 구현한 것이므로 실제 게임과 세부가 다를 수 있습니다
(예: 적 포탑 구역 진입 가능 여부, 턴 순서). 코드는 그런 차이에 대비한 안전장치를 갖고 있습니다.
