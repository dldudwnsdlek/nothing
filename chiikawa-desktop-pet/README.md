# 치이카와 데스크톱 펫 🐻🐱🐰

치이카와 · 하치와레 · 우사기가 모니터 아래쪽(작업표시줄/Dock 위)을 돌아다니는 데스크톱 펫입니다.
**Windows**와 **macOS(인텔/애플 실리콘)** 모두에서 동작합니다. (Electron 기반)

> 캐릭터 그림은 저장소 루트에 올린 사진들(`치이카와_1.jpg` 등)에서 배경을 지워 만든 것입니다.
> 원작 그림의 저작권은 원작자(nagano)에게 있으므로 개인 소장·비상업적 용도로만 사용해 주세요.

## 사용법

앱을 켜면 작은 패널 창이 뜹니다.

| 버튼 | 동작 |
| --- | --- |
| 치이카와 / 하치와레 / 우사기 카드 | 누를 때마다 해당 캐릭터가 화면 가장자리에서 걸어 나옴 (최대 15마리) |
| 다 같이 나와! | 셋이 차례로 등장 |
| 모두 들여보내기 | 전부 화면 밖으로 뛰어서 퇴장 |

캐릭터와 놀기
- **클릭**: 깡충 뛰면서 한마디
- **드래그**: 들어 올려서 흔들기 → 놓으면 던져져서 날아감
- **우클릭**: 그 캐릭터만 집에 보내기
- **쓰담쓰담**: 캐릭터 위에서 마우스를 살살 좌우로 문지르면 💕 나오며 녹아내림
- **말랑 늘이기**: 꾹 누르고(0.35초) 위아래로 당기면 쭈욱 늘어나고, 놓으면 띠용~
- **어질어질**: 들고 좌우로 빠르게 흔들면 머리 위에 ★이 돌고, 내려놓으면 비틀비틀
- **벽에 철퍽**: 화면 옆으로 세게 던지면 벽에 붙었다가 주르륵 미끄러짐
- **탑 쌓기**: 다른 친구 머리 위에 떨어뜨리면 올라타서 같이 다님 (3단도 가능)
- **커서 쳐다보기·따라오기**: 가끔 커서를 졸졸 따라오고, 바닥 근처 커서는 잡으려고 폴짝. 우사기는 커서가 가까이 오면 도망
- 캐릭터가 없는 곳의 클릭은 아래 창으로 그대로 전달되므로 평소처럼 컴퓨터를 쓸 수 있습니다.

### 이벤트 버튼

| 버튼 | 동작 |
| --- | --- |
| 🍙 간식 주기 | 하늘에서 간식이 떨어지고 다 같이 달려감. 먼저 도착한 친구가 냠냠, 늦은 친구는 시무룩 |
| 🚂 기차놀이 | 한 줄로 서서 칙칙폭폭 행진 (캐릭터가 3마리 이상이면 가끔 저절로도 시작) |
| ⚔️ 토벌! | 토벌 괴물 등장 (털복숭이 괴물 / 인어 괴물). 아래 참고 |

### 토벌 이벤트

- 괴물은 가까운 캐릭터에게 덮치기를 하고, 착지하면 주변 캐릭터가 튕겨 나가 어질어질해집니다.
- 우사기는 "우라!" 하며 돌격, 하치와레는 폼폼 응원 + 공격, 치이카와는 울며 도망치다가 가끔 용기 내서 공격합니다.
- **괴물을 클릭**하면 같이 때릴 수 있습니다. HP바가 0이 되면 빙글빙글 사라지고, 다 같이 "토벌 성공!" 춤 + 보상 🌰 이 떨어집니다.
- 45초 안에 못 잡으면 괴물이 "…흥!" 하고 떠납니다. 버튼 없이도 아주 가끔(5분 이상 간격) 저절로 나타납니다.

### 자리 비움

컴퓨터를 5분 동안 안 쓰면 다 같이 잠들고, 다시 마우스·키보드를 쓰면 "어서 와!" 하며 깡충 뛰어 커서 쪽으로 달려옵니다.
(시간은 `src/main.js` 의 `AWAY_SEC` 로 바꿀 수 있어요)

### 축제 · 행운 뽑기 · 기념사진 · 벽타기

| 버튼 | 동작 |
| --- | --- |
| 🎉 축제 | 12초 동안 색종이와 불꽃이 터지고 다 같이 춤추고 뛰어다님 (괴물은 "즐거워 보이네" 하고 떠남) |
| 📸 기념사진 | 친구들이 화면 가운데로 모여 포즈 → 3·2·1 찰칵! 액자 사진이 `사진(Pictures)/치이카와 기념사진` 폴더에 저장되고 잠깐 미리보기가 뜸. 버튼 창의 **폴더 열기**로 바로 열 수 있음 |
| ✨ 행운 뽑기 | 15% 확률로 희귀 이벤트가 바로 일어남. 나머지는 "꽝…" |
| 🧗 벽타기·천장 매달리기 | **ON 으로 켜둔 동안에만** 벽 끝에 간 친구가 벽을 타고 올라가 천장에 거꾸로 매달려 다님. 가끔 손을 놓고 떨어짐. 클릭하면 바로 떨어지고, 드래그로 떼어낼 수 있음. OFF 로 끄면 모두 내려옴. 켜둔 상태는 다음 실행 때도 기억 |

**희귀 이벤트** (버튼 없이도 평균 10분에 한 번쯤 저절로 일어남)
- ✨ **황금 친구**: 반짝이는 황금 치이카와·하치와레·우사기가 화면을 가로질러 지나감. 지나가기 전에 **클릭하면 잡을 수 있음**
- 👑 **왕 친구**: 2배 넘게 큰 친구가 느릿느릿 지나가며 작은 친구들을 튕겨냄
- 🌠 **별똥별**: 하늘을 가로지르면 다들 쳐다보며 "소원 빌자…!"

버튼 창 아래 **도감**에 황금 친구를 잡은 횟수, 별똥별·왕 친구를 본 횟수, 찍은 사진 수가 기록됩니다.

- 패널 창을 닫으면 프로그램이 종료됩니다.

## 그림 바꾸기 / 추가하기

1. 저장소 루트에 캐릭터 사진을 올립니다 (흰 배경일수록 잘 지워집니다).
2. `tools/make_sprites.py` 의 `SOURCES` 에 파일 이름을 추가합니다.
3. `python3 tools/make_sprites.py` 를 실행하면 `src/sprites/` 에 배경이 지워진 PNG가 생깁니다. (Pillow, numpy 필요)
4. `src/characters.js` 의 `SPRITES`(표시 높이)와 `POSE_SPRITE`(어떤 자세에 쓸지)에 등록합니다.

토벌 괴물 그림은 `MONSTERS` 에 등록합니다. 숲·밤하늘처럼 배경이 그림인 사진은 GrabCut 으로 잘라내므로
`pip install opencv-python-headless` 가 필요하고, 괴물이 있는 대략의 영역(x, y, 너비, 높이)을 적어줍니다.

## 실행하기 (개발 모드)

[Node.js](https://nodejs.org) 18 이상이 필요합니다.

```bash
cd chiikawa-desktop-pet
npm install
npm start
```

## 설치 파일 만들기

```bash
# Windows에서 → dist/ 에 설치용 .exe 와 무설치(portable) .exe 생성
npm run dist:win

# macOS에서 → dist/ 에 .dmg 생성 (인텔·애플 실리콘 공용 universal)
npm run dist:mac
```

GitHub에 올리면 `.github/workflows/build-chiikawa-pet.yml` 가 Windows·macOS 설치 파일을 자동으로 만들어 줍니다.
GitHub 저장소의 **Actions → Build Chiikawa Desktop Pet → 최근 실행 → Artifacts** 에서 내려받으세요.
(수동 실행: Actions 탭에서 `Run workflow`)

### macOS에서 처음 열 때

코드 서명이 없는 앱이라 처음엔 "확인되지 않은 개발자" 경고가 뜹니다.
Finder에서 앱을 **우클릭 → 열기 → 열기** 하면 됩니다.
(또는 터미널에서 `xattr -cr /Applications/ChiikawaPet.app`)

### Windows에서 처음 열 때

SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요.

## 파일 구조

```
src/
  main.js        Electron 메인 프로세스 (투명 오버레이 창 + 패널 창)
  preload.js     창 ↔ 메인 통신
  characters.js  자세별 그림 선택 + 움직임/효과
  sprites/       배경을 지운 캐릭터 그림
  pets.js        돌아다니기 행동 AI, 물리, 마우스 상호작용, 간식·기차놀이·자리 비움
  monster.js     토벌 괴물
  events.js      축제, 희귀 이벤트, 기념사진, 화면 효과
  overlay.html   화면 전체를 덮는 투명 창
  panel.html/js  캐릭터 부르기 버튼 패널
build/icon.png   앱 아이콘
tools/make_sprites.py  사진 → 투명 스프라이트 변환
```

새 자세를 추가하려면 `characters.js` 의 `motion()` 에 case를 추가하고,
`pets.js` 의 `BEHAVIOR` 표에 가중치를 넣으면 됩니다.
